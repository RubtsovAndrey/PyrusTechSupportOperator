## 📋 **Архитектура решения**

### **Разделение ответственности:**

#### **В БЗ (MCP) хранятся:**
1. **Знания о проблемах** — инструкции, решения
2. **Метаданные статей** — component, route, onSuccess, onFail и т.д.
3. **Справочная документация** — как размечать статьи

#### **В коде (functions/) хранятся:**
1. **Бизнес-логика переходов** — что делать с метаданными
2. **Проверки и фильтры** — благодарность, вложения и т.д.
3. **Интеграции** — Pyrus, создание подзадач

### **Routing Rules = Документация**
- **НЕ используется** ботом напрямую
- **Используется** редакторами БЗ как справочник
- **Содержит:** шаблоны, примеры, описание полей

## 📝 **Формат метаданных**

### **Рекомендуемый формат:**

```markdown
# Название статьи

\`\`\`yaml
component: POS
route: solver
onSuccess: close
onFail: operator
requiresEmail: false
requiresSubtask: false
priority: normal
\`\`\`

## Содержание статьи
...
```

### **Поддерживаемые поля:**

| Поле | Тип | Описание | Значения |
|------|-----|----------|----------|
| `component` | string | Компонент системы | POS, DodoIS, Staff, Finance, Emergency |
| `route` | string | Сценарий обработки | solver, subtask, escalate |
| `onSuccess` | string | Действие при успехе | close, followup, subtask |
| `onFail` | string | Действие при неудаче | operator, nextStep, escalate |
| `requiresEmail` | boolean | Нужен ли email | true, false |
| `requiresSubtask` | boolean | Создавать подзадачу | true, false |
| `priority` | string | Приоритет | low, normal, high, critical |

## 🔄 **Как это работает**

### **Шаг 1: Поиск**
```javascript
const results = await MCP.searchContent("касса смена 24 часа");
// Находит статью по ключевым словам
```

### **Шаг 2: Получение статьи**
```javascript
const article = await MCP.getContent(results[0].articleId);
// Получает полный текст + метаданные
```

### **Шаг 3: Парсинг метаданных**
```javascript
const metadata = parseArticleMetadata(article);
// {
//   component: "POS",
//   route: "solver",
//   onSuccess: "close",
//   onFail: "operator"
// }
```

### **Шаг 4: Выполнение действия**
```javascript
if (metadata.route === "solver") {
  await sendReply(article.content);
  const status = await askConfirmation();
  
  if (status === "solved") {
    await executeAction(metadata.onSuccess);  // "close"
  } else {
    await executeAction(metadata.onFail);     // "operator"
  }
}
```
