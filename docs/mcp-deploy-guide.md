### **Шаг 2: Деплой через скрипт**

```powershell

```

**Скрипт автоматически:**
1. Проверит, что нет несохранённых изменений
2. Сделает `git fetch` и смержит изменения от платформы
3. Восстановит защищённые каталоги (`docs/`, `tests/`, `tools/`)
4. Проверит, что ни один файл не исчез
5. Запустит тесты
6. Закоммитит и запушит в `main`

### **Шаг 3: Настройка на платформе**

После деплоя нужно настроить MCP-токен в UI платформы:

1. Открыть проект на платформе
2. Перейти в **Credentials**
3. Найти `Knowledge Base MCP Token`
4. Вставить токен: `6682a459-5388-4727-9d8d-fdc0a486e359`
5. Сохранить
